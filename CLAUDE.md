# Project Instructions

## Git

**Nooit zelf committen.** Alle git commits worden door de gebruiker gedaan.
- Maak geen `git commit` aanroepen
- Maak geen `git add` aanroepen
- Laat de gebruiker weten welke bestanden klaar zijn om te reviewen en committen
- GSD workflows: sla commit-stappen over, rapporteer welke bestanden gewijzigd zijn
